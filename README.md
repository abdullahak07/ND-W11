# COMP6012 Week 11 — Operation Cobra

Interactive Week 11 lecture experience for **Threat Modeling and Analysis — Practical Use Cases**.

## Design concept
A cinematic **live intrusion investigation** rather than a slide deck or ordinary card website. Students begin with one reported C2 IP and progressively reconstruct the ABC Company case.

## Interactive learning
- Four-step threat-analysis cycle explorer
- First-move analyst decision
- Multi-stage pivot investigation console
- Drag/click Diamond Model evidence builder
- Cyber Kill Chain gap view
- Exfiltration detector using context + traffic volume
- Volatility/SIFT memory-forensics command chain
- Attribution-confidence challenge
- Interactive spear-phishing/email-forensics inspection
- Ordered MISP event-building workflow
- Eight-question final case review
- Live evidence board that unlocks as the class solves the case

## Lecture coverage
- Identify → contextualise → pivot → discover
- Third-party intelligence validation
- WHOIS, VirusTotal, network/proxy logs and timestamp corroboration
- Diamond Model and Cyber Kill Chain
- FTP exfiltration and Wireshark evidence
- Volatility memory forensics and malware hashing
- Static/dynamic malware analysis and MITRE ATT&CK mapping
- Project Cobra and cautious APT19/Codoso attribution
- Weaponized PDF, spear phishing, email headers and reconnaissance
- MISP feeds, events, enrichment, storage and sharing

## Vercel
Static HTML/CSS/JavaScript. No build step or framework dependencies are required. Import the repository into Vercel and deploy.
