01 / ANALYSIS PROCESS
THE INVESTIGATOR'S LOOP

Pivoting turns one clue into a case.

The analysis process is cyclic, not linear. Every new indicator becomes the next anchor point until no useful pivot remains.

PIVOTrepeat until evidence stops growing
Open analyst notes +

Indicators can be more than IPs. Domains, hashes, URLs, email addresses, bank accounts and metadata can all become anchors.

Validate before spending time. Even an indicator reported by a trusted third party should be independently contextualised.

Stop condition: when you have enough evidence to conclude about the threat and cannot pivot any further.

04 / NETWORK + HOST FORENSICS
FROM TRAFFIC TO PROCESS

Follow the bytes, then follow the process.

Network evidence reveals exfiltration; packet and memory evidence explain how it happened.

GAME 3 · EXFIL DETECTOR

Which transfer deserves the strongest escalation?

Volume alone is not proof. Use context.
WIRESHARK CLUE

Plain FTP exposes the story.

USER admin.test PASS ******** RETR file1.exe STOR collected_data.rar

USER/PASS appear in plaintext. RETR downloads a file; STOR uploads collected_data.rar. With SFTP, the content would be much harder to inspect directly.
